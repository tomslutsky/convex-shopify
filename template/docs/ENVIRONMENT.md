# Environment reference

| Name | Location | Secret | Purpose |
| --- | --- | --- | --- |
| `VITE_CONVEX_URL` | `.env.local` | No | Convex client URL generated by `convex dev` |
| `VITE_CONVEX_SITE_URL` | `.env.local` | No | Convex HTTP actions origin |
| `VITE_SHOPIFY_API_KEY` | `.env.local` | No | App Bridge client ID |
| `CONVEX_SITE_URL` | Convex system env | No | Automatic app JWT issuer and JWKS origin |
| `APP_AUTH_PRIVATE_JWK` | Convex env | **Yes** | ES256 signing key |
| `APP_AUTH_PUBLIC_JWK` | Convex env | No | ES256 verification key; private `d` is rejected |
| `SHOPIFY_API_KEY` | Convex env | No | Shopify client ID used to validate audience |
| `SHOPIFY_API_SECRET` | Convex env | **Yes** | Session-token and webhook verification |
| `SHOPIFY_TOKEN_ENCRYPTION_KEY` | Convex env | **Yes** | Component credential encryption key |
| `SHOPIFY_TOKEN_ENCRYPTION_KEYS` | Convex env | **Yes** | Optional rotation keyring |
| `SHOPIFY_TOKEN_ENCRYPTION_KEY_VERSION` | Convex env | No | Optional active key version |
| `SHOPIFY_SCOPES` | Convex env | No | Must equal the scope source of truth |

Never prefix backend secrets with `VITE_`. The setup wizard retrieves `SHOPIFY_API_SECRET` from the linked app into a protected temporary file, pipes it to the Convex CLI, and immediately deletes the file. It falls back to Convex's interactive secret prompt if Shopify cannot provide it. The checked-in `.env.example` contains names only.
